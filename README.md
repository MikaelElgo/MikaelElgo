# Mikael Elgo

Geophysical Engineering graduate (Institut Teknologi Bandung), currently a geophysicist at PT Mahakarya Geo Survey. I work on seismic processing, subsurface interpretation, and marine geophysical survey — most interested in the path from raw field data to an interpretation someone can actually make a decision on. Growing focus on geomechanics.

## What I work on

• Seismic processing & QC — ProMAX/SeisSpace, PSDM — including onboard marine survey operations

• Reservoir characterization & seismic inversion — Petrel, Hampson-Russell — 3D seismic + well logs, AI/SI/EEI

• Petrophysics and well-log analysis

• Python for geoscience: data QC, machine learning, and 1D geomechanical modeling

## Selected work

• Poseidon 1D Mechanical Earth Model — independent Python workflow: depth-consistent framework from logs, deviation surveys, checkshots, and formation tops, with input QC and documented calibration gaps. Kept explicitly screening-level and uncalibrated.

• Multi-well lithofacies prediction — ML pipeline on the FORCE 2020 dataset using leave-well-out (group) validation to test generalization to unseen wells; tree- and gradient-boosting classifiers compared.

• Talang Akar reservoir characterization (BSc thesis) — 3D seismic and six wells, AI/SI/EEI inversion for sandstone distribution. Full write-up in my portfolio.
